# Lush Engineering Website

A responsive company website for **Lush Engineering Proprietary Limited**, a Botswana-based electrical and mechanical engineering services company.

The website presents the company's profile, service areas, project information, compliance information, and contact options.

## Website features

- Company introduction and engineering services overview
- Electrical and mechanical service information
- Dedicated compliance and projects sections
- Contact and quotation enquiry section
- Responsive navigation with a mobile menu
- Scroll-based navigation and page animations
- Service information modals
- Background hero video

## Built with

- HTML5
- CSS3
- JavaScript

The site is organised as a static front-end project.

## Project structure

```
lush-engineering/
├── index.html
├── styles.css
├── script.js
├── images/
└── videos/
```

## Run locally

Open `index.html` in a browser, or serve the project directory using a local development server.

For example, with Python installed:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment

Deploy the project directory to a static hosting provider or web server. Keep the image, stylesheet, JavaScript, and video asset paths available so the page can load its resources.

## Notes

Company details and service descriptions on the website should be confirmed with the company before relying on them for business or procurement decisions.
